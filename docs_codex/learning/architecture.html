01 · Cheshire/CVA6/Ara 系统架构

SoC、标量处理器与向量加速器的职责、接口和系统层次。

SoC 组件职责与系统连接MIPS 与自定义总线的概念对照RTL、测试平台与软件的层次关系系统实例的源码阅读练习
学习目标

指出 printf、普通访存、向量运算分别需要谁；分清 RTL、testbench、软件和平台封装。前置：组合/时序逻辑、CPU 取指执行、C 函数调用。

SoC 组件职责与系统连接

在 MIPS 处理器中，ALU 执行加法只需要寄存器与运算资源；要输出字符，还需要地址译码、外设寄存器、串行发送器、时钟以及初始化软件。片上系统（System on Chip，SoC）就是把这些资源接成可运行系统的集成层。

CVA6负责标量 CPU：取指、译码、整数/浮点运算、特权状态、异常、地址翻译和一级缓存。Ara负责 RISC-V 向量扩展（RISC-V Vector，RVV）：接受 CPU 发来的指令与操作数，通过向量寄存器、运算 lane（并行数据通道）和向量访存单元 VLSU 工作。Cheshire提供互连、存储路径、调试、启动和外设集成。

MIPS 与自定义总线的概念对照

MIPS / 自定义系统经验在本工程中的对应理解类比边界
CPU 核 + 外设顶层CVA6 + Cheshire 集成SoC 不只是核的别名；地址属性、cache、调试影响可见行为
CP0 状态与异常寄存器CSR：mstatus、mtvec、mepc、mcause寄存器编号、权限、异常入口和返回语义不同，不能直接移植 CP0 代码
req/ack 自定义总线AXI VALID/READY 的传输确认AXI 地址/数据/响应通道独立，有突发与多个在途事务，不是一根 ack 全部完成
专用协处理器Ara 由 CVA6 指令驱动此组合的 cvxif 命名端口不是任意 IP 可插的标准插槽；gen_cva6_cfg 设置 CvxifEn=0
神经网络专用阵列未来 NPU（Neural Processing Unit，神经网络处理器）Ara 是通用向量执行器；NPU 常用任务描述符、DMA、专用精度与片上复用，编程与性能模型不同

RTL、测试平台与软件的层次关系

层本仓库入口谁在“运行”它
RTL（寄存器传输级，Register Transfer Level）cheshire_soc模拟器求值，或综合成硬件；描述真实逻辑
Testbench（测试平台，TB）与 VIP（验证环境组件）tb_cheshire_soc → fix → dut 与 vip主机模拟器生成时钟/复位、加载 ELF、解码 UART、判结束；不是芯片内固件
裸机软件（bare metal）crt0.S 与应用 C目标 CPU 执行指令；没有 OS 不等于没有运行时、链接器或驱动
平台 shell / wrapper（封装）cheshire_top_xilinxFPGA 板级时钟/引脚/DDR；未来 ASIC wrapper 要对接工艺资源

编译 ELF 没有“生成 CPU”。编译 RTL 也没有“把 C 烧进去”。FPGA bitstream 配置硬件逻辑；ELF 携带软件字节和装载信息，两者可以在不同时间更新。

源码依据 · 源码静态确认
hw/cheshire_soc.sv：gen_cva6_cores、gen_ara、i_axi_xbar、i_llc、BootAddr；hw/cheshire_pkg.sv：gen_axi_in/out、gen_cva6_cfg。向量端口的类型与实际连线比端口名字更有证明力。

系统实例的源码阅读练习

工作目录：仓库根。工具：rg。输入：当前 SoC 源码。输出：终端行号，无构建产物。

rg -n 'gen_ara|i_axi_xbar|i_llc_atomics|i_llc \(|boot_addr_i|BootAddr' hw/cheshire_soc.sv
rg -n 'SelectedCfg|fixture_cheshire_soc' target/sim/src/tb_cheshire_soc.sv

成功判据：能找到 CPU 与 Ara 各自接互连的证据，能指出 TB 参数在哪里传递。常见错误是拿依赖中的 ara_soc 代替当前仿真顶层；先看启动脚本 TESTBENCH，再跟 fixture 到 dut。此静态练习无仿真超时，文件缺失时先确认当前目录与 HEAD。

自测
1. 没有 Ara，CPU 能执行 printf 吗？

可以，若标量 ISA、启动、UART 与软件相匹配。printf 不天然需要向量扩展。

2. TB 里的 C++ ELF loader 在 RISC-V CPU 上执行吗？

不。它由主机 C++ 编译器生成，通过 DPI 与模拟器互调；目标端执行的是 ELF 中的 RISC-V 指令。

3. HelloWorld 板测证明了 DDR 和 Ara 吗？

必须看实际 ELF 的地址、指令与硬件路径。SPM 上的标量输出不能证明 DDR 全功能，也不能证明 RVV 执行。
