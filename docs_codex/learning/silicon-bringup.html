39 · 首硅启动与系统可观测性

首硅早期状态观测与存储、计算能力的分阶段验证。

本章任务

为未来首硅安排一条逐步扩大依赖的正常启动路线，并说明每一步应该留下什么可复查证据。前置：启动链、复位与就绪、制造测试边界。当前没有 ASIC 样片，本章是可提前完成的验证设计。

39.1 最小启动系统的可观察性

从完整 Linux、DDR 和向量程序一起启动，很难区分哪项前提尚未建立。首个闭环应只依赖电源、参考时钟、复位、ROM/片上存储和一个可观察入口：确认 CPU 能取指、能在已知可写内存保存状态，执行小段标量程序并给出结果。然后才把外存、复杂驱动与并行计算加入。

这条路线需要在设计阶段保留入口。JTAG 需要其 PAD、供电、复位和调试路径都可用；UART 输出需要控制器时钟、分频和引脚有效；测试点或状态寄存器也要有可访问的时钟域。用依赖 DDR 的日志缓冲判断“DDR 是否已启动”会形成循环，因此早期状态先保存在已知可用的片上资源或独立观察通道。

39.2 候选首硅启动与结果校验流程

  1. 记录样片与板级输入。把芯片批次/版本、板卡版本、固件与 ELF 哈希、启动脚选择、电源和参考源条件写入运行记录。上电电压和顺序依真实芯片/PAD/板规范制定，本页不填写猜测值。
  2. 建立有效时钟与复位。按平台契约确认参考源、PLL 或安全旁路状态，再按各域要求释放复位。观察的是对应状态或测试点；“给软件写了配置”不等于电气条件已达成。
  3. 观察 ROM 与片上存储。调试入口允许时读 PC/指令或阶段标志。保留 LLC 的基线等待 tag BIST、配置 SPM，再建立栈；用限定保留区域做写读校验，不覆盖 ROM、代码、栈和他人数据。调试读回与 CPU 自己运行的读写结果分别记录。
  4. 进入标量应用并输出。确认 crt0 到 main 的初始化，计算已知小数组，与独立参考逐项比较；UART 发送版本、判定和计数，并等待发送语义要求的完成。输出字符证明这条链走通，不能直接扩大为 Ara 正确。
  5. 开放 DDR。初始化代码和栈继续放在已验证片上资源。控制器/PHY 按供应商协议就绪后，才在预留外存区域做地址、数据和访问宽度测试，再迁移程序或大缓冲。范围和使用者必须明确，不对未知介质或正在使用的数据做破坏测试。
  6. 加入 Ara 与系统负载。核 profile/ISA/VS 等前提，运行现有向量例子并逐项比对结果；再扩大到 DMA、图像设备和多主并发。每次新增一项依赖，保存输入、完成条件、错误状态及最终数据。

本地非零 Platform ROM 普通返回仍有 S01-B01，动态调频、MIG ready 放行和 Ara 目标执行也各有未验证项；选择实验前必须按系统诊断/实现状态与Ara 诊断核适用条件。本页步骤是未来目标路线，不是这些问题已经修复。

39.3 启动阶段标志与状态观察

阶段标志最好同时表明“准备做什么”和“完成到哪里”。例如先记录将进入平台初始化，正常返回后再记录平台初始化完成；若只有一个笼统 boot_ok，后续无法判断它是否已经覆盖 DDR。复位原因、构建版本与阶段状态应在合适的保留域中读取；当前没有设计出的新寄存器不可写成现有地址。

读 PC 是观察 CPU，读控制器状态是观察设备；CPU halt 后 Ara、DMA 或外设是否仍运行取决于本地调试连接。调试操作前需要明确哪些执行者停止、哪些仍会改内存。运行时正常观察应尽量不改变被测对象；读取带清除副作用的状态寄存器，必须按其接口语义安排。

39.4 正确性、性能与功耗的测量边界

先验证结果，再记录一轮任务从提交到完成、从输入到输出的不同时间边界。CPU 周期数、设备活动周期和墙钟时间不天然相等；控制频率变化、等待、搬运与 OS 调度都影响解释。现有计数器/寄存器先盘点真实可读项，再提出需要新增的性能观测接口。实际测量方法见实验与测量。

若论文要报告功耗，还需要能隔离或解释目标电源轨的测量点、采样方法和仪器，并说明包含或排除了 DDR、PHY、PAD 与板上稳压损耗。整板电源读数不能无依据地命名为 Ara 核功耗。当前没有样片或这些测量输入，本章不提供任何频率、功耗或加速数值。

39.5 启动验证证据与后续交付条件

证据能够支持的结论仍需另外验证
用户历史 VCU118 HelloWorld 报告当时平台的相应程序与输出路径成功本轮源码对应性、ASIC、Ara、DDR 全功能
当前源码静态推演预期连接、前提、等待条件与缺口实际执行、模拟/物理条件与结果
未来具体运行的原始日志和独立数据比对该版本/环境/输入/范围内的运行结果扩大输入、并发、温度电压范围及性能统计
制造测试、STA、物理报告各自对象和模型下的检查结果软件系统与应用结果仍需单独回归

进入执行前需要 P01/板级团队提供样片、板资料、供电/参考源、探针与仪器；S01 提供带版本和结果检查的最小固件；V01 维护范围与判据；M01/I01 提供外存和设备条件。现在可以写完这条路线及预期，不能把资料到位前的推演记为首硅通过。

启动依赖核对本地 Boot ROM、SoC与平台初始化约定；工程范围以02 提取交接书为准。本章是基于这些接口的验收方案建议，未在 FPGA 或 ASIC 上重新执行。

首个外存测试为什么仍把代码和栈放在片上？

它先独立验证 DDR 的访问能力，避免测试自身取指、栈和日志已经依赖尚未建立的存储条件。成功后才扩大使用范围。
