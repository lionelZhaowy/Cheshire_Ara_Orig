## 本章自测

**看到 REG\_OFFSET 就可以无副作用读取吗？**

不可以。iDMA NEXT\_ID 读取会提交任务，bus error 的 ERR\_CODE 读取会弹出记录，UART RBR 读取会取走数据。先查访问语义。

**头文件中的所有索引都能访问吗？**

不一定。还要确认实例数量、参数化寄存器生成版本及地址译码范围。先用 HW\_FEATURES 和硬件配置核对，禁止靠扫描未知 MMIO 探测。
