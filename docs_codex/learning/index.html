这套教材面向具备 RTL、处理器和 C 基础，正在学习 RISC-V 平台软件的工程师。沿一份数组程序，依次建立程序、地址、存储、数据协作、启动和系统配置的关系，再进入操作系统与 ASIC 集成。

主阅读路径与知识依赖

推荐顺序是：平台职责与 CPU 使用模型 → C 程序的编译、链接和装载概览 → 地址译码与 AXI → Cache、LLC/SPM 与 DDR 边界 → iDMA、Ara 与共享数据 → 详细启动和外设运行 → 时钟、复位和配置 → OS、扩展集成与验证。前四章先建立从源代码到 main 的全流程；理解存储和事务之后，再解释 Boot ROM 如何准备运行环境、加载器如何放置程序。

首次实践可在编译链接章节完成实验 A：ELF 布局观察；读完启动与 JTAG 接管后，按实验 B：装载运行进入仿真操作。实验页提供直接步骤，不要求先读完 ASIC 章节。当前配置中不具备运行条件的实验会明确给出门槛，预期输出不能当作实测结果。

贯穿示例与各类文档职责

137 项数组示例贯穿 C 对象、初值/BSS、链接布局、装载、逐项校验和 UART 输出；Ara 使用相同结果规格解释向量分块。OS 章节继续解释同一调用和缓冲区在任务、进程中的变化。LVDS→ISP→NPU→Ara 的帧处理是未来集成案例。

查询参数、地址、寄存器配置参考、地址空间、寄存器索引按子系统查字段、默认/覆盖关系与修改影响，不以字典代替教程。

当前实现、项目目标与验证边界

CVA6 承担控制与通用计算；Ara 承担向量计算，包括 NPU 不适合的部分浮点向量运算。目标是加入自研 ISP、NPU、LVDS 与外购 AXI4 DDR。当前源码中有 CPU/Ara、互连、LLC/SPM 和 FPGA DDR 集成参考，新 IP、独立片上 Global Buffer、Ara 分流及 DDR 旁路还没有实现。近期主 Xbar 保持 64-bit 的需求与 GB 讨论以M01 接口契约为准，不能据示意图认定已连接。

用户报告的 VCU118 HelloWorld 不等于本轮重新板测，也不能扩展为 Ara、DDR 全功能或 ASIC 就绪。Platform ROM 返回路径、iDMA 控制通路及目标运行缺口保持开放。RTOS/Linux 的教程和上游支持不等于当前镜像已经启动；OS 移植也不是裸机 ASIC 提取的前置条件。当前结果见本轮文档检查，历史实验保留原日期和输入。
