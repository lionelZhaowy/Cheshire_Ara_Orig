Cheshire / CVA6 / Ara
按知识体系查阅，沿同一程序实践

这是一部面向具备 C/RTL 基础读者的工程教材。七篇按系统职责组织，章内用节和小节表达依赖。第一次动手可走下面的短路线；时钟电源、互连细节和扩展规划在需要时再读。

首次运行 C 程序的短路线

  1. 01 系统架构 → 02 指令能力与 CSR → 03 起步配置 → 07 地址图：明确当前程序能使用什么。
  2. 13 运行模型 → 14 工具链与 ELF → 实验 A：构建同一数组程序并检查布局。
  3. 15 ROM 与应用初始化 → 16 JTAG 接管 → 17 仿真 → 实验 B：装载、执行、逐项校验并让注错正确失败。

实际 RTL 编译、目标运行和板测仍按证据页列出的缺口验收。按目录读完全部硬件设计章节不是开始实验 A 的前置条件。

贯穿示例与阅读方法

journey.c 从 137 项标量数组开始，检查初值、BSS、逐项结果和总和 28085。向量实践仍用同一 main，逐步比较汇编、intrinsics、自动向量化、尾部及归约。六项实验共享构建—配置—执行—数值—错误证据链，不以反汇编或一行 PASS 代替所有结论。

侧栏默认展开当前篇，并列出当前章的节；页内目录同时展示节与小节，可折叠。手机可收起全书目录，关闭 JavaScript 仍可用原生目录和静态图。WaveDrom 图标为教学时序，真实波形必须另外关联运行记录。

第一篇 · 系统基础与配置

  1. 01 · 整体架构与平台边界 — 沿取指、数组与字符输出辨认模块职责。
  2. 02 · CVA6 功能与 RISC-V 系统基础 — 把 ISA、CSR、访存与实现资源联系起来。
  3. 03 · Cheshire、CVA6、Ara 与软件配置 — 按真实字段及消费者建立自洽组合。

第二篇 · ASIC 时钟、复位与电源

  1. 04 · 时钟系统与 PLL — 区分时钟域、使能、同步器和平台时钟源。
  2. 05 · 复位体系与平台启动条件 — 从请求生命周期定义复位、就绪与恢复。
  3. 06 · 电源域与低功耗规划 — 区分现有 RTL 边界和待实现的电源契约。

第三篇 · 互连与存储系统

  1. 07 · 地址空间与访问属性 — 分别核对路由窗口、实际容量和 CPU 属性。
  2. 08 · AXI 通道、突发与握手 — 沿真实握手语义理解一笔读写事务。
  3. 09 · AXI Crossbar 结构与事务路由 — 追踪译码、仲裁、W 路由、ID 与响应。
  4. 10 · 接口适配与 RegBus — 解释位宽、协议、ID 转换及跨域边界。
  5. 11 · Cache、LLC/SPM 与存储路径 — 区分缓存副本、地址别名与共享物理阵列。
  6. 12 · DDR 控制器、PHY 与 AXI4 接入 — 从平台初始化到软件可用建立交付条件。

第四篇 · 裸机软件、启动与验证

  1. 13 · 裸机 C 程序运行模型 — 从对象、调用和初始化理解存储布局。
  2. 14 · 工具链、链接与 ELF — 让同一数组程序形成可解释的装载产物。
  3. 15 · Boot ROM、启动模式与应用初始化 — 分别追踪 ROM 服务、自主加载和应用入口。
  4. 16 · JTAG 与程序加载调试 — 核实外部调试接管的真实等待条件。
  5. 17 · Questa/VCS 仿真与结果验证 — 按阶段检查输入、运行、数值和退出。

第五篇 · 外设、事件与数据搬运

  1. 18 · MMIO 驱动、UART 与 GPIO — 从寄存器语义推进到初始化与引脚行为。
  2. 19 · 定时器与中断系统 — 建立计时、使能、服务、清源与返回闭环。
  3. 20 · I2C 与 EEPROM — 从线路、FIFO 和控制寄存器到器件读取。
  4. 21 · SPI、NOR 与 SD — 把控制器事务和外部设备协议分开。
  5. 22 · iDMA、流量管理与总线错误 — 理解搬运提交、完成、限流与故障门槛。
  6. 23 · Serial Link、VGA 与 USB — 按设备追踪控制、数据、时钟及验证条件。

第六篇 · Ara 向量执行与异构协作

  1. 24 · Ara 结构与 CVA6 协处理器接口 — 分清请求、应答、CPU 提交和实际完成。
  2. 25 · RVV 编程与结果验证 — 用同一数组比较汇编、intrinsics 和自动向量化。
  3. 26 · CPU、Ara、DMA 与 NPU 的共享数据 — 建立可见性、所有权和有界恢复协议。

第七篇 · IP 集成与 ASIC 工程规划

  1. 27 · 自定义 IP 的控制、数据和中断接入 — 从独立 Reg 单元逐步进入系统。
  2. 28 · LVDS、ISP、NPU 与外部 DDR 集成 — 逐 IP 明确接口、缓冲、跨域和验收交付。
  3. 29 · 模型任务划分与容量带宽预算 — 用透明假设衡量 Ara/NPU 协作成本。
  4. 30 · 固定配置工程与 ASIC 集成验收 — 冻结可搬迁输入并形成分阶段实现证据。
