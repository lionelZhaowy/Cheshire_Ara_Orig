当前复位入口与作用域

系统复位、调试复位和局部接口复位

rst_ni 是 SoC 的主要低有效复位，test_mode_i 属于测试控制；JTAG 的 TRST/TCK 管理调试传输，USB PHY 有自己的时钟/复位接口。复位域按真正接到的寄存器及同步逻辑划分，不能仅凭模块名推断独立复位能力。

入口或状态当前连接边界不应扩大的结论
rst_niCPU、Ara、互连、LLC 与大多数系统逻辑释放不代表外部 DDR 训练已完成
JTAG TRST调试传输入口；与系统时钟域有 DMI 交互不等于重启所有系统设备
DM ndmreset_ocheshire_soc 中输出未使用写调试复位请求不证明存在芯片级复位控制
USB / Link有各自接口域与局部控制；Link 隔离输出未接成系统闭环局部寄存器复位不自动清除所有下游在途事务

把复位释放和工作就绪分开

ROM 可执行、SPM 可装载与应用可运行

CPU 取到 ROM 指令只证明复位取指路径开始工作。LLC BIST、SPM 配置、栈建立、平台 ROM、ROM C 服务各是后续状态。JTAG VIP 在 LlcNotBypass 时只轮询 CFG_SPM_LOW.bit0 后发 halt；这不是 ROM C 测频完成标志，也不能凭该位单独证明 ROM 已执行完扩展栈步骤。具体接管流程见调试章。

DDR 与外部设备的就绪

外部 DDR 需要时钟/复位、控制器初始化、PHY 训练以及平台允许发请求；接口能返回某个控制寄存器，不证明数据阵列可用。先让诊断程序及栈留在已验证的 SPM，再逐级开放外存。未来平台应给每个就绪等待定义截止时间、错误原因及回退路径。

复位释放与平台就绪

复位通常要求异步进入安全状态、在每个工作域同步释放；此原则需要与库单元、DFT 和 IP 的要求一起验证。DM 的 ndmreset_o 在当前 SoC 中未使用，不能当作现成的全芯片复位源。Link 的隔离相关端口也不能证明已实现可独立掉电的域。

事务中途复位与恢复

停止新请求，再处理已接受事务

已经接收 AW 而没有收完 W 或返回 B 的目标，不能直接掉时钟；未返回的读 burst 也不能静默丢弃。正常停止应停发新请求，等各层队列和返回排空，必要时由经过设计的隔离/终止机制向上游报告错误，再执行复位。超时意味着需要恢复策略，不意味着硬件自动停止写内存。

最小验证场景

分别在地址等待、数据背压、响应等待和 CPU 轮询时请求停止，检查完成或错误都能有界结束；复位后不应把旧事务的完成归给新任务。异步进入、同步释放、跨域握手和复位原因寄存器要落实到平台 RTL 后再验证，本轮没有实现这些新机制。
