CVA6 功能组成与对外行为

取指前端提供指令，译码/发射决定执行操作，功能单元算结果，提交阶段让架构状态按要求生效。cache miss、依赖和异常会停顿或撤销工作，所以外部 AXI 流量既不是“每条指令一笔”，也不能直接当成退休指令数。本章不展开各级流水线门级实现。

功能块原理与外部可见行为配置学习重点
I/D cache用 tag 判断请求的数据行是否已保存在近端；命中常不发 AXI，缺失才取回容量、路数、行宽和 WT/WB；缓存启用状态也影响行为
MMU/TLB/PTWTLB 缓存虚拟→物理翻译；缺失可触发页表遍历，产生额外访存硬件有 MMU 不等于裸机开启翻译；访问权限与 cacheability 也不是一件事
FPU执行浮点，状态许可由 FS 等控制硬件能力、软件 ABI、运行时许可三者分别核对
预测器/队列尝试减少控制流等待、容纳在途操作；错误预测需撤销参数会改变存储量/控制复杂度，不据容量直接承诺 IPC
加速器接口发送向量指令、标量操作数和提交/撤销信息，并接收状态当前 RVV 专用通路，不是任意 CV-X-IF IP 都能替换

CPU 运行状态与故障观测

程序不动先查 reset、启动 PC 和指令取回；非法指令查 mepc 对应机器码、profile、decoder、VS/FS；访问异常查地址、翻译/保护、互连响应。AXI 没有流量先判断是否 L1 命中或指令还未到访存，不应立刻判断 crossbar 坏了。更多软件定位见仿真闭环。

本章自测

开了 Cfg.Ara 为什么 CPU 还可能不发向量指令？

CPU profile 的 RVV 与 decoder 独立选择，且软件需实际执行 RVV 并启用状态。

WT 是否代表没有缓存？

不是。仍有读缓存和写缓冲；外部 DMA 写入不因此自动更新 CPU 副本。

调大预测器一定更快吗？

不能保证。收益依赖分支行为，也可能增加面积/关键路径；需要明确工作负载与时序测量。
