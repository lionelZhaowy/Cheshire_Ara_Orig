一条连续的学习路线

先确认硬件提供什么，再解释配置怎样落实为结构。随后从一个小 C 程序建立变量、栈与初始化模型，追踪它经过工具变为 ELF、被加载进内存、由复位后的处理器执行。输出和错误判据建立后，再深入外设、共享存储及向量计算，最后讨论接入新 IP 与未来平台。

贯穿示例与阅读方法
