SoC 启动与平台接口条件

模块语法检查通过仅证明语法满足编译要求。启动还依赖正确时钟、复位释放、BootAddr、地址路由、可返回数据的ROM/存储模型以及异常/调试状态。若取指请求已发出但没有返回，需要查存储和桥；若根本没取指则先查reset与debug halt。

时钟域连接与工艺适配

通用SoC大部分组件在clk_i/rst_ni域；RTC是同步输入后生成计数使能。FPGA shell提供时钟资源，MIG提供DDR UI域并经axi_cdc连接主域。USB另有PHY时钟接口，Serial Link有源同步接收边界。VGA分频计数是状态机使能，不应见到clk_div字段就画一个新时钟域。

已有源码时钟复位图记录locked/MIG校准完成未纳入当前放行路径、USB复位域需验证等边界。这些是待验证集成问题，不在本轮替生产工程改线。未来ASIC需按工艺替换PLL、PAD、SRAM宏及DDR控制器/PHY，FPGA的XPM/MIG/MMCM不是ASIC工艺单元。

复位过程与在途事务管理

单比特异步复位释放通常需遵循目标域的同步释放约束，但只加同步器并不保证系统事务恢复。设备收到AW后被复位，上游还在等B怎么办？跨域FIFO一侧清空，另一侧保留旧指针怎么办？应规定停止新请求、排空/隔离、复位、重新初始化和恢复接收的顺序，并覆盖对端不响应的超时分支。

电源门控还需隔离、保持和唤醒时序，不能由时钟门控推导而来。当前未有完整UPF/CPF证据，Serial Link的隔离/门控输出也未在SoC形成完整控制闭环；本教材不虚构CPU/NPU独立电源域。

平台初次运行与分阶段验收

  1. 先证明时钟复位、BootAddr与ROM读返回；记录首个有效PC，不只看波形有跳变。
  2. 证明SPM读写和栈；再运行不依赖复杂外设的整数计算。
  3. 证明UART寄存器写与TX帧；之后才用printf当诊断通路。
  4. 分别验收外部DDR与跨域桥的边界地址、字节写、长burst和错误响应。
  5. 最后加入中断、DMA、Ara并发；每次只引入可定位的新条件。

本章自测

RTL同一根reset是否意味着所有时钟域都安全？

不是。释放时序、同步链和事务状态都要按域检查，尤其是异步桥和独立PHY。

读到了第一条ROM指令就证明DDR可用吗？

不能。ROM、片上SPM和外部DDR是不同目标与初始化路径。

关闭时钟是否等于设备已经安全隔离？

不是。仍可能有未完成事务或悬挂输出；需要停止、排空、隔离与握手协议。
