Cheshire / CVA6 / Ara
从一个程序走到操作系统与ASIC

读者已经掌握MIPS、自定义总线、SystemVerilog和C。本书先用同一数组程序建立RISC-V系统、软件和设备的关系，再学习向量、操作系统和ASIC实现。目录是一条完整学习顺序；下面的首次实践是它的前缀，主题链接用于回查。

先把一个程序运行过程讲完整

先读系统、CVA6使用模型和最小配置，再沿C对象→编译链接→ELF→ROM/外部装载→crt0→main→库/驱动→UART。至此可完成实验A的布局观察；具备对应目标条件时，再沿实验B装载运行。实验B链接了仿真操作步骤，不要求首次学习就读完全部ASIC章节。

之后按目录解释地址、AXI和存储，掌握异常/外设正常过程，再学习Ara、OS和多设备协作。PLL、工艺宏、CDC/RDC、PAD、时序和制造测试在已有系统模型上展开。例子是否可执行由具体前提和未验证项说明；没有运行证据的预期输出不是实测结果。

用同一任务连接各层

137项数组串起C对象、初值/BSS、调用、装载、逐项校验和UART输出。Ara沿同一结果规格解释向量分块；OS用任务切换和同一设备调用解释运行环境怎样改变。未来LVDS→ISP→NPU→Ara的一帧过程属于方案案例，不代表这些新IP已经接入。

每章先推演一次正常工作，再落到本地实例与关键配置。参数/API完整字典留在参考；异常、中断、背压、访问副作用和结果完成是正常机制。故障树、已知缺陷与恢复移到独立诊断，影响当前例子可执行性的限制仍在正文短示并链接。
