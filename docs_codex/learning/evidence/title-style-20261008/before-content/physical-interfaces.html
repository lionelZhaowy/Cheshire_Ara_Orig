本章任务

沿 I2C 的一个 ACK 位，把 SoC 逻辑端口连接到 PAD、封装、PCB 和器件，明确每一层负责什么。前置：I2C 正常读事务。不指定尚未提供的 PAD 型号、封装脚位和电压。

一个 ACK 为什么需要同时看输出和输入

I2C 控制器发送八位后，在第九个时钟期间释放 SDA，让目标器件拉低 SDA 表示 ACK。控制器随后读取引脚的实际电平。这里存在两条路径：输出使能控制“本端是否驱动”，输入接收器观察“线上现在是什么”。关闭本端输出不等于把输入置高；线上还可能有目标器件正在拉低。

本地 SoC 把 SDA 和 SCL 都拆为 *_o、*_i、*_en_o。方向以 SoC 为参照：o 是输出值，en_o 是输出允许，i 是实际线路反馈。它们是内部逻辑信号，不是具备 ESD、防过压和规定驱动能力的芯片引脚。ASIC 顶层的 PAD 把这些逻辑信号转换为电气接口，封装与 PCB 再把接口连到器件。

沿当前 FPGA 连接理解未来边界

当前 cheshire_top_xilinx 用两只 IOBUF 连接 I2C。以 SDA 为例，I=i2c_sda_soc_out、O=i2c_sda_soc_in、IO=i2c_sda_io，而三态控制为 T=~i2c_sda_en。所以 en=0 时，T=1 让 FPGA 输出成为高阻态，输入仍反映线路。这个极性关系可以从本地接线确认；ASIC PAD 的使能脚可能不同，必须依它的手册转换。

层同一根 SDA 经过什么本工程已经有/仍待提供

把 IOBUF 改名为某个 PAD 并不是完整替换：其 I/O 电压、输入容限、输出驱动、上拉能力及供电状态都要匹配。正常 reset 期间应让总线保持规定的释放状态；若 PAD 域与内核域供电不同，还要落实电平转换和掉电隔离。逻辑仿真中的 1 与外部引脚的安全电压是两种判断。

释放线路如何形成高电平

普通双向 I2C 开漏模式允许设备拉低或释放线路，高电平由上拉产生；任何参与者拉低时，线路为低。这使控制器发送 1、目标 ACK 和时钟延展能够共存。选择上拉时，过弱会使总线电容充电太慢，过强则要求器件在低电平时吸收更大电流。两者同时限制阻值，而不是“放一只常见电阻”就完成电气设计。

对选定模式，可用器件允许的低电平电压与下拉电流估计最小上拉电阻，用允许的上升时间和总线电容估计最大值；最终须加入 PAD、器件、封装和板线的真实条件。这里没有这些输入，故不填写阻值或工作电压。上拉所在电源域在 SoC 关电时是否仍有电，也要按 PAD 的容限与回灌限制设计。

开漏、ACK、时钟延展及上拉选择的协议依据：NXP UM10204 Rev.7.0（2021-10-01），3.1、7.1 节；本页限定普通双向模式，没有据该规范宣称本地支持所有 I2C 速率。接线依据：cheshire_soc I2C 端口与FPGA IOBUF 实例。

复用和上电状态也是正常操作的一部分

如果目标芯片把同一 PAD 复用于 GPIO 和 I2C，CPU 在启用控制器前必须先完成复用选择，使输出值、OE 和输入反馈都接向同一个功能。不能只切输出而让输入仍取另一条线。切换应在相关功能停止驱动后进行，按 PAD/IP 定义建立默认状态；这是一份未来 pinmux 契约，当前通用 SoC 端口没有自动提供完整芯片复用系统。

完整 ACK 过程现在可以连续复述：供电与上拉有效 → PAD 处于 I2C 功能且输入可用 → 控制器在八位发送后释放 SDA → 目标在第九时钟拉低 → 低电平经 PCB/封装/PAD 输入返回 i2c_sda_i → 控制器形成收到 ACK 的状态。正常使用与预期结果在I2C 章；无 ACK 的逐层排查在外设诊断。

差分图像输入要先确定物理接收职责

未来 LVDS 图像接口不能只在顶层增加两根 logic。先确定传感器输出的差分电气规范、线对数量、串行速率、转发时钟、位/字边界和上电时序，再决定由何种接收 PHY/PAD 完成差分判决、采样和解串，数字逻辑才接收像素或字流。封装管脚、PCB 对内/对间偏差和终端的允许范围来自所选发送/接收资料；“LVDS”这个名称不定义整套图像帧协议。

本轮没有传感器/接收 IP 完整资料，不推定通用 GPIO PAD 可直接接入，也不冻结终端阻值、速率、线数或引脚。I01 提供帧格式和正常流量，P01/供应商提供接收电气与 PHY，板级负责人提供实际互连。接收到的数字流如何进入缓冲，见图像系统集成。

SoC 的 sda_en_o=0 后，输入一定是 1 吗？

不一定。它表示本端释放；输入取决于上拉、电容和所有外部驱动。ACK 时目标器件恰好应把它拉低。

FPGA IOBUF 的 DRIVE=12 能否直接变成 ASIC PAD 的规格？

不能。它属于 FPGA primitive 的配置语义；ASIC 需要所选 PAD 库、电压和负载条件。替换要保持接口与电气要求，不能复制数值当工艺结论。
