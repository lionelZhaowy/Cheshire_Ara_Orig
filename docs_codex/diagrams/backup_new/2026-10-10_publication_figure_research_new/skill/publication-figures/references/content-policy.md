# 图面、图注与记录

| 输入信息 | 放置位置 | 例子 |
| --- | --- | --- |
| 对象/端口/关键机制 | 图面 | `LLC / SPM`、`S0`、`Tag [47:14]`、`MUX` |
| 影响阅读的状态 | 短标签/线型+图注 | `proposed` 或虚线边界；图注明确哪些路径未实现 |
| 配置、成立条件、箭头语义 | 紧邻图的 caption | 三口假设依赖 NPU 与 GB 共用搬运出口；请求箭头省略返回通道 |
| 细节解释、教学推导 | 正文或配套 README | COMMIT 接收和刷新结束的差别、地址算例 |
| 来源/提交/测试/日志 | provenance / 交接 | 源路径、哈希、Office 是否测试 |

不要把“如何读这张图”“尚未板测”“我们讨论的三种方案”等自动画成外围框。不要为简洁删掉候选状态、关键开关选择、实际数据方向或容量守恒。将旧文字移到图注时，建立具体映射，避免必要条件只留在不可见的内部思考中。

交付用词区分：源码确认、用户确认、教学举例、候选方案、实际验证。术语简短不等于把不同 IP 合并；若名称太长，换行或使用图注定义的缩写。
