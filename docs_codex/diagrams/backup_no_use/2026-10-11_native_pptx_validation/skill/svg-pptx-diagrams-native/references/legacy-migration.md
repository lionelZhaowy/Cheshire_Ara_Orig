# 旧图迁移

旧 skill 按图元导出，line + polygon 本来就是两个对象，离散 dash 小线段也没有完整边界的语义。保真转换时继续保留它们；本版不会用“距离很近”作为自动合并依据，因为那可能合并相邻但独立的信号、实心连接点或真正的三角模块。

用户要求修复旧图时，读取 SVG 和预览，确定每条线的起终点、箭头方向、关联三角形和虚线轮廓。

1. 把同一支箭头的线段连接成一条 line/polyline/path，终点设为原箭头的尖端，移除它对应的独立箭头 polygon，添加支持的 marker-end。双向情况同时用 marker-start。不能简单把原来停在三角底边的线加 marker，否则会缩短路径。
2. 将同一轮廓的虚线段重建为 rect/ellipse/闭合 path，设置 dasharray。保留不属于该边界的真实短线。
3. 在新目录保存母版和产物。比较新旧几何、颜色、端口位置与必要文字；箭头尺寸从任意旧三角形归一到原生中号三角形时，记录该视觉变化，不宣称逐像素保真。
4. 检查报告 native_arrow_objects/native_dashed_objects，查看 PPT 对象数量及实际预览。不要只对旧 PPT 点“组合”就声称已经成为原生端点。

本 skill 不批量猜测历史文件的箭头关系，不自动改写已存在图稿。旧的 assets/example.svg 保留为回归输入；assets/native_example.svg 展示推荐的新图表达，含直线、反向、双向、折线、曲线与虚线框。
