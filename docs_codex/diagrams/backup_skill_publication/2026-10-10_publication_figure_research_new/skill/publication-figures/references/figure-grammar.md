# 按关系选图式

这些是领域常见图式与工作建议，不是某会议强制视觉规范。

| 内容 | 优先图式 | 容易误画的地方 |
| --- | --- | --- |
| 电路 | 器件/运放/比较器/开关符号、节点与反馈环；时钟相位另画 | 不能用圆角“处理模块”代替待解释的真实电路；交叉线不自动相连 |
| SoC / AXI | 发起端→适配→路由→目标端；端口命名沿各 IP 视角 | 一个框不能掩盖独立端口仲裁；逻辑请求方向不等于 AXI 全部通道方向 |
| Cache / SPM | 地址字段、tag 与 data 阵列、索引/比较/选择、容量与映射 | Cache way 由命中/替换选，不能凭空加到 cache 地址字段；同阵列复用不能画成复制 |
| 时间与流水 | 同一时间轴、多执行资源泳道，标出停顿/重叠 | 无测量数据时只标示意，不给虚构周期；精确数字波形优先 WaveDrom |
| AI 方法 | tensor/feature maps→实际算子→分支/融合；训练和推理分开 | 不给所有模块换一套“Input/Process/Output”模板；维度、共享权重、残差归属要一致 |
| 对比和消融 | 同尺度、同图例、面板对齐；变量变化清晰 | 不把有利裁剪或不同坐标范围伪装成公平比较 |
| 芯片照片/视觉结果 | 来源明确的独立图像面板+矢量标注 | 本版原生导出器不支持 image；不能据此删去实验图像或悄悄整图压平 |

电路图通常压缩重复器件但保留关键晶体管/节点；体系结构图通常通过端口、阵列与资源归属解释机制；视觉方法图允许更多语义色和实际图像。不存在一套“顶会通用配色”。先确定学术论点，再选择图式。
