QuestaSim/VCS 实验环境要求

  1. 工具与许可：当前可定位Questa2024.1；未验证许可证或RTL兼容性。VCS/vlogan不在PATH，实际版本未知；需在目标安装环境回传version、host C++、可用DPI/SV能力。
  2. 编译/展开：独立清单、单一RVV profile/真实decoder、本地模型齐备；实际vlog/vlogan及DPI编译、vsim/vcs展开必须成功，Bender导出不算此关。
  3. 启动/装载：ROM完成SPM、reset释放、JTAG halt/load/resume、入口与段校验；修复/验证loader段尾问题，先跑最小标量Hello/array。
  4. 外设专项：GPIO/timer已有可构建例；I2C/NOR需模型/时序，DMA先解决lane；USB/VGA/SD/引脚GPIO需要各自环境补齐，不能要求同一个默认fixture覆盖全部。
  5. 验收证据：每例保留配置、命令、ELF SHA、compile/elaborate/simulate日志、UART、退出码、超时和最小波形；正常+反例都过预期判据后再称跑通。

回传最小包：工具版本（不含密钥）、HEAD/本地补丁摘要、实际profile/SELCFG/宏、ELF及map/dump、第一处编译/展开错误上下文；若已运行，再加最后进展、PC/CSR、等待寄存器与对应短波形。不要发送许可证密钥或受限供应商源码。
