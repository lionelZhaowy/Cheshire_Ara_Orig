# 交接模板：<任务 ID> / <主题>

首次为实质进展创建 `handoffs/<任务ID>_<主题>.md`；同主题后续更新原文件，不按日期另建。普通答疑不生成交接，技术说明写入正式文档并在需要时链接。独立评审可用 `_review` 后缀，保留角色和证据边界。不要直接把结果填回本模板。
